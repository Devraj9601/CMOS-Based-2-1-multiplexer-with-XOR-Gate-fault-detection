# CMOS Based 2:1 multiplexer with XOR Gate fault detection



## Overview
A CMOS-based 2:1 Multiplexer integrated with an XOR gate for real-time fault detection. The design was implemented and simulated using Cadence Virtuoso with 90nm GPDK CMOS technology.

## Features
- CMOS 2:1 Multiplexer
- XOR-Based Fault Detection
- Low Power Design
- Cadence Virtuoso Simulation

## Tools Used
- Cadence Virtuoso
- 90nm GPDK CMOS Technology


## Applications
- Fault-Tolerant VLSI Systems
- FPGA Systems
- AI Hardware Accelerators
